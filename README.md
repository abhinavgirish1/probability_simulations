#Probability Simulations

This repository contains small simulations to build intuition around probability and random variables.

## 1. Dice Even/Odd Probability Simulation

This simulation estimates the probability of even and odd outcomes when
rolling a fair six-sided die. For each value of n, the die is rolled n times
and the fraction of even and odd results is recorded.

The results show high variance for small n and convergence towards 0.5
for both probabilities as n increases, which is consistent with the
Law of Large Numbers.

This experiment is intended to build intuition for probabilistic
convergence using simple Monte Carlo methods.
