# PRV26 Programming Assignment

All solutions written as part of an assignment for the course Probability and Random Variables (PRV).

## What's in each notebook

- **Question_1** — simulating a biased coin using only fair coin tosses
- **Question_2** — rejection sampling for an exponential-type distribution
- **Question_3** — Box-Muller for normals, ECDF plots, likelihood ratios
- **Question_4** — checking exponential and Gaussian samples against theory
- **Question_5** — sampling from a 3D multivariate normal
